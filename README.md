# 🧬 Estudar Biologia

Bem-vindo ao repositório de apontamentos e recursos para o estudo de Biologia.

## 📌 Conteúdos
- 🧫 **Biologia Celular:** Estudo da célula, organelos e processos metabólicos.
- 🧬 **Genética:** DNA, RNA, hereditariedade e expressão génica.
- 🌿 **Botânica & Ecologia:** Ecossistemas, fotossíntese e biodiversidade.
- 🫀 **Anatomia & Fisiologia:** Sistemas do corpo humano.

## 🚀 Como Usar
Este espaço serve para organizar resumos, mapas mentais e exercícios resolvidos.
